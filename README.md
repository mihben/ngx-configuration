# ngx-configuration

The `ngx-configuration` packages provide ease-to-use solution for handling configuration in [Angular](https://angular.dev) webapplications.

With the help of the `ngx-configuration-core` package the application configurations can be red from JSON file. Also capable to handle different settings for different environments (Production, Development...).</br>
The `ngx-configuration-options` package is capable to map different sections of the red configuration to separated objects.
